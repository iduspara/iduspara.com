## Why I built it

Developers love sharing code on social media, but plain screenshots of an editor rarely look good. I built Codeimg.io so anyone can turn a snippet into an image that's ready to post.

## What it does

- **Social network templates** with the right canvas sizes for Facebook, Twitter and Instagram, or a custom size.
- **Canvas, window and editor settings** to style the background, the window frame and the code itself.
- **One-click download** of the finished image.

## Feedback

I collect feature requests and bug reports in a public GitHub repository, so users can tell me what they'd like to see next.
