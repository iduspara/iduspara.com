## Why I built it

I love the craft of macOS interfaces, and I spend most of my days in the shadcn/ui ecosystem. CupertinoUI brings the two together: real macOS 27-style components that I can drop into any React project and own, just like regular shadcn/ui components.

## What's inside

- **70 free components** under the MIT licence, with a theme that supports light and dark mode and every macOS accent colour.
- **Pro components and app blocks**: complete windows such as Finder, Mail, Notes, Safari and Calendar.
- **A live desktop demo** with draggable, resizable windows and a working Dock.

## How it works

CupertinoUI is delivered as a **shadcn registry**. I add the registry namespace to `components.json`, install the CSS theme file, and pull components in with the shadcn CLI. The code is copied into the project, so it stays fully editable. Under the hood I build on **Base UI** primitives for accessible behaviour.

## Business model

The core is free and open. Pro is available as a yearly plan or a one-time lifetime licence.
